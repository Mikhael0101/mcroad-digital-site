McRoad Digital — Pinterest App Privacy Policy

Last updated: October 10, 2026. Operator: McRoad Digital. This policy covers our proposed Pinterest app, not our Seller Profit Tracker workbook or Gumroad checkout. For non-sensitive privacy questions, use our public GitHub issue contact route or our McRoad Digital Pinterest profile. Do not post passwords, tokens or personal information in public issues. The app is under development and is not currently connected to the Pinterest API.

Current data practices

We have not enabled Pinterest OAuth or collected Pinterest authorization codes, access tokens, profile information, board data or Pin data through this app. We do not publish Pins through this app. This static policy page contains no forms, analytics scripts or tracking pixels, and McRoad Digital sets no cookies on the page. Our local demonstration uses fictitious data and does not connect to Pinterest.

Hosting and technical requests

This page is hosted on GitHub Pages. GitHub logs and stores visitors' IP addresses for security purposes, regardless of whether visitors are signed into GitHub. GitHub may process other technical information under its Privacy Statement. McRoad Digital does not receive GitHub's security logs through this static page and has not added tracking scripts, cookies or forms. This informational policy page does not host checkout, commercial transactions or a software service.

Future changes

Our proposed app would let the account owner select and approve each individual educational Pin before a publishing action. Connecting an account alone would not authorize publishing. We do not propose automatic bulk posting, advertising or access for outside users. Before enabling any real OAuth connection or Pinterest API data handling, we will implement appropriate access controls, decide what data is needed, where it is stored, how long it is retained, how to delete it, and which providers receive it. We will update this public policy to state those actual practices before activation. No future data processing is promised or authorized by this pre-launch policy.

Questions

For questions about this proposed integration or its privacy practices, contact McRoad Digital using our public GitHub issue route for non-sensitive questions. Do not post personal information or credentials there. If we begin processing personal data, we will provide a workable route for access and deletion requests and describe that process here before launch.
